Why

Teams need the power of an autonomous agent without exposing credentials, losing session ownership, or operating without usage visibility.

What

A local workspace for versioned agent specifications, validation, publishing and rollback, runtime teams, task tracking, scheduled runs, and knowledge and memory controls.

Current focus

Enterprise SSO, broader role-based access control, multi-user reliability validation, and production hardening remain ongoing.

System architectureFrom agent design to a running conversation

The portal is the user interface. FastAPI owns identity, workspace data, and orchestration. Hermes executes the agent work. Agent configuration and request execution are separate paths.

Follow one chat request

  1. Send. The portal sends the message using the signed-in user’s session.
  2. Prepare. FastAPI checks ownership, searches document knowledge, and attaches the session’s agent instructions and delegation policy.
  3. Execute. Hermes runs the agent and may delegate to team members, use tools, or consult its configured memory provider.
  4. Return. FastAPI relays SSE events to the portal and records activity. Approval requests are presented for human review.

Development status: These components exist in local development. Enterprise SSO, broader RBAC, multi-user reliability validation, and production hardening remain ongoing. Local setup documentation is available; the enterprise repository and recorded demo remain unreleased.

Prototype status & limitations

Hermes Enterprise is a locally developed AI workspace and agent factory built with Next.js, FastAPI, and Hermes Agent. It supports versioned agent specifications, validation, publishing and rollback, runtime teams, approval workflows, task tracking, scheduled runs, and knowledge and memory controls. Enterprise SSO, broader role-based access control, multi-user reliability validation, and production hardening remain ongoing. Local setup documentation exists. The enterprise repository and recorded demo are not yet publicly released.
