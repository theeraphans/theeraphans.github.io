Technical decisions & boundaries

  1. Source boundary

    The public architecture groups business sources because internal system names and connection details are not disclosed.

  2. Pipeline ownership

    Airflow schedules the data workflow. Docker packages the environment; it is not a separate data-processing stage.

  3. Reusable modeling

    SQL and dbt establish warehouse models that downstream consumers can reuse instead of rebuilding reporting logic.

  4. Consumer boundary

    Power BI and automation depend on the shared models. Specific refresh schedules, warehouse vendor, and adoption figures are not claimed here.
